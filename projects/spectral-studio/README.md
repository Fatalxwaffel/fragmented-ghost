# Spectral Studio

React source for the Fragmented Ghost audio visualizer and recording studio.

## Local development

```bash
pnpm install
pnpm run dev
```

## Verify and build

```bash
pnpm run typecheck
pnpm run build
```

The production build is written to `apps/spectral-studio/`, which is served at `/apps/spectral-studio/` by the static Vercel site.
